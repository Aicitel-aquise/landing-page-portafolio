Contenidos

Lo que aprenderás en el curso

Una ruta práctica orientada a iniciarse en el control de versiones con Git y a publicar proyectos utilizando GitHub.

01

Introducción a Git

¿Qué es el control de versiones? Ventajas, instalación, configuración inicial y creación de tu primer repositorio con git init.

02

Seguimiento de cambios

Aprende a preparar cambios con git add, registrar historiales con git commit y revisar el estado del repositorio con git status.

03

Repositorios remotos

Conecta tu proyecto con GitHub mediante git remote add origin, sincroniza con git push / git pull y gestiona claves de acceso.

04

Trabajo colaborativo

Ramas, fusiones, resolución de conflictos y flujo de trabajo en equipo para proyectos compartidos.

05

Buenas prácticas

Mensajes de commit claros, uso de .gitignore, organización de repositorios y publicación de tu landing page.

06

Proyecto integrador

Aplica todo lo aprendido creando, versionando y desplegando este proyecto de ejemplo en GitHub.

Acerca del curso

Ingeniería de Software - INS-600

Esta asignatura tiene como objetivo introducir las herramientas y metodologías para el desarrollo de software, poniendo especial énfasis en el control de versiones y la colaboración con Git y GitHub.

  • Gestión: II-2026
  • Modalidad: Práctica con ejercicios guiados y proyecto integrador
  • Enfoque: Aprendizaje basado en casos reales y trabajo en equipo
Objetivos

Formar desarrolladores colaborativos

Al finalizar el curso, serás capaz de inicializar repositorios, gestionar el historial de cambios, trabajar con ramas, conectar con repositorios remotos y colaborar efectivamente en proyectos de software.
